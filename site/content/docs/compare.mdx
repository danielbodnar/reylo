## SQL tools

Reylo isn't the first tool to type SQL: [sqlc](https://sqlc.dev), [sqlx](https://github.com/transact-rs/sqlx) and [PgTyped](https://pgtyped.dev) have typed queries for years, and [Prisma TypedSQL](https://www.prisma.io/docs/orm/prisma-client/using-raw-sql/typedsql), [SafeQL](https://safeql.dev), [TypeSQL](https://github.com/wsporto/typesql) and [Postgres Typed SQL](https://github.com/fli/postgres-typed-sql) do it too.

## ORMs and query builders

[Prisma](https://www.prisma.io/orm), [Drizzle](https://orm.drizzle.team), [Kysely](https://kysely.dev) and [TypeORM](https://typeorm.io) type the queries you build in TypeScript, from a schema kept in your code.
